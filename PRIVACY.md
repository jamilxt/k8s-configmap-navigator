# Privacy Policy — K8s ConfigMap Navigator

*Last updated: November 19, 2026*

**K8s ConfigMap Navigator** is a free, open-source JetBrains IDE plugin developed by **jamilxt**.

## Data Collection

**K8s ConfigMap Navigator does not collect, store, transmit, or share any personal data, source code, configuration values, telemetry, or usage analytics.**

- All file scanning, indexing, and navigation happen **100% locally** inside your JetBrains IDE.
- Plugin settings (such as optional external ConfigMap or project directory paths) are stored strictly locally in your IDE project configuration (`.idea/k8sConfigMapNavigator.xml`).
- The plugin makes **zero network requests**.
